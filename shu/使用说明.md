这是一份给「没写过代码」的伙伴看的操作手册。你只需要会三件事:打开文件、改几个数字/文字、按 F5 运行。**全程不需要写任何代码。**

## 1. 一分钟看懂这个项目

| 文件 / 文件夹 | 是什么 | 你要不要动 |
|---|---|---|
| `scenes/tile.tscn` | 一个格子的样子 | 改格子美术才动 |
| `scenes/player.tscn` | 角色的样子 | 改角色美术才动 |
| `levels/levels.json` | 所有关卡 + 格子颜色 | 改关卡 / 改颜色才动 |
| `scenes/main.tscn` | 主场景(骨架) | **不要动** |
| `scripts/` | 游戏逻辑(代码) | **不要动** |
| `shaders/` | 卡通渲染效果 | **不要动** |

记住一句话:**美术改 `.tscn`,关卡和颜色改 `levels.json`,其余一律别碰。**

## 2. 怎么运行游戏

1. 用 Godot 打开这个项目(双击 `project.godot`)。
2. 按键盘 **F5**(或点右上角 ▶ 播放按钮)。
3. 游戏开始。

操作按键:
- **W / A / S / D** —— 按住蓄力,松开跳出去;**按得越久跳得越远(最多 3 格)**;屏幕下方**蓄力条**显示当前能跳几格,蓄满变金色
- **← / →** —— 左右移动圆圈到要填的空位

> 每次改完文件,都要**重新按 F5 运行**才能看到效果。

## 3. 改格子长什么样(美术)

格子在独立文件 `scenes/tile.tscn` 里。在 Godot 左侧「文件系统」面板双击它,你会看到:

```
Tile (根节点)
├─ Base        ← 格子的底座(圆台)
└─ NumberLabel ← 格子上的数字
```

### 3.1 换格子的模型(形状)
1. 双击打开 `scenes/tile.tscn`。
2. 在左侧「场景」面板选中 `Base`。
3. 右侧「检查器」面板找到 **Mesh**。
4. 把你的 3D 模型文件(`.glb` / `.gltf` / `.obj`)拖进 Godot 的文件系统面板,再把它拖到 **Mesh** 那一栏上。

> 格子会按数字自动染色。如果你的模型自带贴图、不想被染色,见「常见问题」。

### 3.2 调数字的位置 / 大小
1. 选中 `NumberLabel`。
2. 检查器里改 **Font Size**(字号)、**Pixel Size**(数字的 3D 实际尺寸)。
3. 或者在中间的 3D 视图里,直接用鼠标把数字拖到想要的高度/位置。

## 4. 改角色长什么样(美术)

角色在 `scenes/player.tscn` 里,双击打开:

```
Player (根节点)
├─ Shadow     ← 脚下阴影
├─ Body       ← 身体(黄色球)
├─ EyeL / EyeR   ← 眼睛
├─ CheekL / CheekR ← 腮红
├─ Mouth      ← 嘴
└─ ChargeRing ← 蓄力环(平时隐藏)
```

### 4.1 换身体模型
1. 选中 `Body`。
2. 检查器 **Mesh** 换成你的模型(和格子一样:拖文件进项目 → 拖到 Mesh)。

### 4.2 调五官
在 3D 视图里直接拖动眼睛/腮红/嘴;或在检查器里改它们的 **Position**。

### 4.3 换颜色
选中对应节点(如 `Body`),检查器里展开 **Material Override** → 改 **Albedo Color**。

## 5. 改关卡(布局 + 题目)

所有关卡都在一个文件里:**`levels/levels.json`**。用记事本 / 任意文本编辑器打开它。

它长这样(节选):

```json
{
  "tile_colors": ["#ff9aa2", "#ffb7b2", "……"],
  "start_color": "#b5e6c3",
  "levels": [
	{ "equation": "? + ? = 3",  "grid": [[1, 2, 3], [4, 5, 6], [7, 8, 9]], "start": [1, 3] },
	{ "equation": "? + ? = 10", "grid": [[1, 2, 3], [4, 5, 6], [7, 8, 9]], "start": [1, 3] }
  ]
}
```

### 5.1 改题目(equation)
- `?` = 玩家要填的空位(就是那个圆圈)。
- 每个符号之间**用空格分开**。
- 目前支持 `+` 和 `-`,数字用正整数。

| 你想出的题 | 就写成 |
|---|---|
| 1+2=3,两个空位 | `"? + ? = 3"` |
| 5−3 结果未知 | `"? - ? = ?"` |
| 三空位求和 | `"? + ? = ?"` |

### 5.2 改格子布局(grid)
`grid` 就是九宫格,每行一个方括号,数字 1~9 随便怎么排:

```json
"grid": [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]
```

- **第一行 = 屏幕上方(远处)**,最后一行 = 屏幕下方(近处)。
- 想让某个位置**没有格子**,写 `0`。例如:

```json
"grid": [
  [1, 0, 2],
  [0, 3, 0],
  [4, 0, 5]
]
```

> ⚠️ **题目里需要的数字一定要出现在格子里**,否则这关永远解不出来。比如题目是 `? + ? = 3`,格子里就得有 `1` 和 `2`(或能凑出 3 的数字)。

### 5.3 改起点垫位置(start)
`start` 是角色一开始站的地方,格式 `[列, 行]`。默认 `[1, 3]` = 九宫格下方正中间。

### 5.4 加一关
在 `levels` 的方括号 `[ ]` 里,复制其中一段,粘贴到**最后**,改数字即可。记得上一段的结尾要加逗号 `,`。

## 6. 改颜色

在 `levels.json` 的顶部:
- `tile_colors` —— 9 个格子的颜色,按数字 **1→9** 的顺序。
- `start_color` —— 起点垫的颜色。

颜色用 `#` 加 6 位字符表示,例如:

| 颜色码 | 大概是 |
|---|---|
| `#ff9aa2` | 粉色 |
| `#ffd166` | 黄色 |
| `#a2d2ff` | 天蓝 |
| `#ffffff` | 白色 |

不知道颜色码?在浏览器搜「颜色选择器」,点出喜欢的颜色,复制它的 `#xxxxxx` 码即可。

## 7. 常见问题(FAQ)

**Q: 改了 JSON 之后游戏没变化 / 报错了?**
A: JSON 很严格,逗号 `,`、引号 `"`、括号 `{}` `[]` 一个都不能少、不能多。写错时游戏会自动退回内置关卡,并在底部「输出」面板显示红色错误。回去检查标点。

**Q: 格子被染成了奇怪的颜色?**
A: 格子会按数字自动染色。若你的模型自带贴图,打开 `tile.tscn` → 选中 `Base` → 在检查器里把 **Material Override** 清空(点它右侧的 ↺ 图标)。

**Q: 数字怎么不见了?**
A: 格子里写 `0` 表示「这里没有格子」。想让数字显示,写 1~9 的数字。

**Q: 改了没反应?**
A: 改完必须**重新按 F5 运行**才生效。

**Q: 角色怎么不动了?**
A: 确认键盘焦点在游戏窗口上(点一下游戏画面)。

## 8. 坐标速查表

- **列(col)**:从左到右 0、1、2
- **行(row)**:从上到下 0、1、2(0 在最上、最远)
- **起点垫**:默认 `[1, 3]`(在九宫格下方)

```
     列0    列1    列2
行0   (0,0)  (1,0)  (2,0)   ← 屏幕上方(远)
行1   (0,1)  (1,1)  (2,1)
行2   (0,2)  (1,2)  (2,2)   ← 屏幕下方(近)
             (1,3) 起点垫
```
